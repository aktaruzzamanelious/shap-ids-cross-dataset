# Data

Raw datasets are **not** included in this repository (size and license terms).
Download them yourself, place the raw files under `data/raw/`, then run the
preprocessing notebooks. Processed splits are written to `data/processed/` by
the notebooks and are also excluded from version control.

## Datasets

### UGRansome2024

- Source: Kaggle
- Authors: Azugo et al. (2024)
- URL: https://www.kaggle.com/datasets/azugo/ugransome2024
- Access: requires a free Kaggle account
- Version downloaded: 2024-08-27

### CICIoT2023

- Source: Canadian Institute for Cybersecurity (CIC), University of New Brunswick
- Authors: Neto et al. (2023)
- URL: https://www.unb.ca/cic/datasets/iotdataset-2023.html
- A Kaggle mirror also exists; the official CIC distribution above is the
  authoritative source used for this work.
- Access: submit the data-access request form on the CIC page
- Version downloaded: 2025-04-21

## Layout expected by the notebooks

```
data/
  raw/
    UGRansome_Dataset_2024.csv      # from the UGRansome2024 download
    CICIOT23/                       # from the CICIoT2023 download
      train/train.csv
      test/test.csv
      validation/validation.csv
  processed/                        # generated by notebooks 01 and 02
```

## Steps

1. Download both datasets from the URLs above.
2. Place the raw files in `data/raw/` following the layout above.
3. (Optional) make raw files read-only: `chmod 444 data/raw/*.csv`.
4. Run `notebooks/01_data_cleaning.ipynb` then `notebooks/02_preprocessing.ipynb`
   to generate the processed train/test splits.

A helper, `download_datasets.sh`, automates the UGRansome2024 download via the
Kaggle CLI. CICIoT2023 requires manual acceptance of the CIC access form and is
not scriptable.
